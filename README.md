# 🐧 Pengus — Gamified Travel Savings & AI Coach

Pengus is a web application designed to help users set, track, and achieve travel savings goals through gamification, custom mascot outfits, milestone celebrations, and an AI Budget Coach.

## ✨ Features
- **Destination Milestone System:** Visual milestones for worldwide destinations (Tokyo, Rome, Bali, London, etc.).
- **Interactive Pengus Mascot:** Mascot reacts to savings progress and changes into destination-themed outfits (Kimono, Gondolier, etc.).
- **AI Coach Screen:** Dynamic budget calculations tailored to trip duration, accommodation style, flight tiers, and dining habits.
- **Micro-Interactions & Audio:** Sound effects, celebration modals, confetti, and glassmorphic UI.

## 🛠 Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons
- Canvas Particle Animations

## 🚀 Quick Start
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
